ROB RUN 繁體中文化 v3.0.0
================================================================

【這是什麼】
把遊戲的介面、任務、道具、地名、提示等文字換成繁體中文（臺灣用語），並補上能
顯示繁體中文的字型。翻譯由本專案從遊戲英文原文直接翻譯。

本包不含任何遊戲檔案：安裝時會讀取你電腦上的遊戲原版檔案，在你自己的電腦上
產生中文化檔案。

【安裝前】
1. 完全關閉遊戲（工作管理員裡也不能有 ROB RUN.exe）
2. Windows 10 / 11（64 位元）
3. 第一次安裝需要連網（下載約 10 MB 的 Python），以及約 300 MB 暫存空間

【安裝】
按兩下「一鍵安裝.bat」。
  · 會自動尋找遊戲；找不到時，照畫面提示貼上遊戲資料夾路徑
  · 第一次會在 %LOCALAPPDATA%\ROBRUN_zhTW\python 準備專用的 Python，
    不影響你電腦上原有的 Python
  · 最後顯示「安裝完成！」就成功了

【切換成中文】
進遊戲：設定 → 其它 → 語言 → 選「繁體中文」→ 確定
（「繁體中文」使用的是原本「俄語」的位置，其他語言不受影響）

【解除安裝】
按兩下「解除安裝.bat」。中文化檔案與暫存會全部刪除，遊戲回到原版。

【運作方式】
  · 中文化檔案以新檔名 *_zht.bundle 放進遊戲資料夾，原版檔案不會被修改
  · 切換是靠改寫使用者資料夾裡的資源索引快取：
    %USERPROFILE%\AppData\LocalLow\Kefir\ROB RUN\com.unity.addressables
  · 記錄檔：%LOCALAPPDATA%\ROBRUN_zhTW\log.txt

【遇到問題】
1. 黑畫面／閃退／進不去 → 先執行「解除安裝.bat」回到原版，確認遊戲本身正常
2. 沒有出現中文         → 確認語言選的是「繁體中文」；看安裝畫面有沒有 [錯誤]
3. 卡在下載 Python       → 檢查網路或防毒軟體，再試一次
4. 遊戲更新後失效       → 重新執行「一鍵安裝.bat」；大改版時可能要等中文化更新

【注意】
· 這是玩家自製的非官方中文化，與開發商 Kefir 無關
· ROB RUN 是有反作弊的線上遊戲，使用風險請自行承擔
· 遊戲新增的文字在翻譯更新前會顯示原文
